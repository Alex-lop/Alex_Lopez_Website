# Project asset provenance

- `graphene-lockup.svg` is Graphene's logo lockup (the tree mark, one branch pruned, beside the wordmark), ink with the pruned branch in gray, on transparent (the ink-on-ivory lockup without its ivory box), the same mark as the README of https://github.com/Alex-lop/Graphene and https://alex-lop.github.io/graphene-site/. It replaced `graphene-mission-control.webp`, the earlier G-of-nodes banner (see git history).
- `imc-prosperity-3.webp` is the IMC Prosperity 3 key art, restored from commit `7e7b4bb`.
