Graphene

A visual way to see what you can build next with an agent

August 2026. Python 3.13, FastAPI, Google ADK, MCP SDK, Textual, SQLite, Cytoscape.js. Apache-2.0.

  • 939test functions across 129 files
  • 209commits in 19 days
  • 25known limitations, each naming its fix

Graphene on GitHub

I kept leaving an agent running for hours and having no idea, at a high level, what it had done. The only way to find out was reading thousands of lines of a markdown file. The last time I wrote CSS was junior year of high school — sitting through a YouTube tutorial I realized I'm never going to need to write it again, because of AI. If an agent can get to a solution that's honestly better than what you could've come up with in a day, you use it. Then you feel disconnected, like you're just guiding it down a path and hoping it gets it right.

Tokens are going to be cheap. How a developer works with an agent isn't going to be bounded by tokens. It's the ability to actually create initiative. Graphene tries to answer that with a visual approach to the decisions that can be made, because the limit for most developers is just that: knowing what to build next. Not another ledger of callbacks. A way to actually collaborate with the agent instead of steering it and hoping. Still working on this, and most likely going to submit it to a hackathon (probably the NVIDIA x Nebius hackathon).

Nemisis

Crash-safety verification for AI-written retry patches

August – September 2026. Python 3.12+, uv, pydantic, MCP SDK, pytest. v0.2.0 on PyPI, Docker 77 MB, Apache-2.0.

  • 634tests on CPython 3.12 – 3.14
  • 600 / 600nightly red-team agreement
  • 14turns for a fresh agent to prove its own fix

GitHub Live page

A payment webhook credits an order twice when the worker dies mid-handler. An ordinary test cannot catch that: it calls the handler once, with nothing going wrong. The agent's patch ships green and still double-charges.

CrashCheck runs the patched handler in a real worker and SIGKILLs it the moment the effect is on disk. A fresh worker starts, the event is redelivered, and an independent read says what survived. The model never judges. 600 of 600 generated handlers agreed with an independent oracle. Not proven: anything outside two scenarios, one handler shape, SQLite and POSIX SIGKILL.
